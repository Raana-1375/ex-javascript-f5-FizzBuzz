# Word Order Reverser Project

## Description
This project implements a function that reverses the order of words in a provided string.

## Requirements
* **Inversion:** The order of words must be reversed.
* **Data Cleaning:** Leading and trailing spaces are removed.
* **Intermediate Spaces:** Multiple spaces between words are reduced to a single space.
* **Empty Input:** Empty strings or strings with only spaces return an empty string.
* **Punctuation:** Punctuation marks remain attached to their respective words.
