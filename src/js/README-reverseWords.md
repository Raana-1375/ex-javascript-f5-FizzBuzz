# Word Order Reverser Project

## Description
[cite_start]This project implements a function that reverses the order of words in a provided string[cite: 7].

## Requirements
* [cite_start]**Inversion:** The order of words must be reversed.
* [cite_start]**Data Cleaning:** Leading and trailing spaces are removed.
* [cite_start]**Intermediate Spaces:** Multiple spaces between words are reduced to a single space.
* [cite_start]**Empty Input:** Empty strings or strings with only spaces return an empty string.
* [cite_start]**Punctuation:** Punctuation marks remain attached to their respective words[cite: 15].
