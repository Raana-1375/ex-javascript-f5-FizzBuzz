# English Word Checker

## Algorithm
1. Receive an input string of arbitrary length.
2. Convert the entire input string to lowercase to ensure the search is case-insensitive.
3. Check if the transformed string contains the exact substring "english".
4. Return `true` if it matches, otherwise return `false`.
