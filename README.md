# FizzBuzz Project
## Features
- Prints numbers from 1 to 100.
- Replaces multiples of 3 with "Fizz".
- Replaces multiples of 5 with "Buzz".
- Replaces multiples of both 3 and 5 with "FizzBuzz".
- Fully tested with a dedicated test case for each scenario.
