## Features & Test Scenarios
The project includes a robust test suite covering 5 distinct scenarios using Vitest:
1. **Normal Numbers:** Returns the number itself if not a multiple of 3 or 5.
2. **Fizz Scenario:** Returns "Fizz" for multiples of 3.
3. **Buzz Scenario:** Returns "Buzz" for multiples of 5.
4. **FizzBuzz Scenario:** Returns "FizzBuzz" for multiples of both 3 and 5.
5. **Error Handling:** Throws an error if the provided data is not a number (e.g., a string like "hola").
